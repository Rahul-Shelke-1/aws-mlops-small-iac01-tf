# AWS Small MLOps Platform

An open-source AWS MLOps platform built with Terraform, Python, and automated testing. It provides a modular foundation for secure, scalable, and reproducible cloud infrastructure, with CI/CD workflows, infrastructure validation, documentation, and release automation.

## Project Goals

- Build reusable AWS infrastructure using Terraform.
- Establish secure and reproducible infrastructure provisioning.
- Validate infrastructure code through automated testing.
- Automate code quality checks and CI/CD workflows.
- Maintain versioned documentation and releases.

## Development

Start with the [Getting Started](getting-started.md) guide to configure the local development environment and run the initial checks.

## Project Status

The project is currently establishing its development environment, testing conventions, and automation foundations. Infrastructure modules and deployment workflows will be introduced incrementally.
